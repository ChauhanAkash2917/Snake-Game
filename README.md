[🐍 Snake Game](https://chauhanakash2917.github.io/Snake-Game/)

An interactive and fun Snake Game built using JavaScript, HTML, and CSS. Control the snake, eat the food, and avoid collisions to achieve the highest score! 🎮🔥

🚀 Features

🎵 Background music & sound effects (Food, Movement, Game Over)

🏆 Score & High Score tracking (stored in local storage)

🐍 Smooth snake movement

🍎 Random food generation

⚡ Simple & responsive UI

🛠️ Installation & Setup

Clone the repository

git clone https://github.com/ChauhanAkash2917/snake-game.git

Navigate to the project folder

cd snake-game

Open index.html in a browser

open index.html

OR simply double-click index.html to start playing!

🎮 How to Play

Use Arrow Keys to control the snake:

⬆️ Up Arrow - Move Up

⬇️ Down Arrow - Move Down

⬅️ Left Arrow - Move Left

➡️ Right Arrow - Move Right

Eat the food to grow in size and increase your score!

Avoid colliding with the walls or yourself.

Try to beat your high score!
